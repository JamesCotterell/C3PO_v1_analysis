C3PO v1 — Analysis Code

This repository contains Python code used for analysis and generation of figures for Cell 3D Positioning by Optical encoding (C3PO) and its application to spatial transcriptomics, accepted for publication in Cell Systems.

This repository contains research code used to perform the analyses described in the Methods and generate the figures presented in the manuscript. It is provided primarily for transparency and reproducibility and is not intended as a general-purpose software package.

Repository contents

Reproducibility

The code is provided to support transparency and reproducibility of the analyses reported in the manuscript.

The scripts were developed and executed in the research environment used for the study. Some scripts may require adaptation of file paths or input-file locations for use in other environments.

Data

The datasets required for the analyses are not necessarily included in this repository. Where applicable, publicly available datasets and accession numbers are provided in the manuscript.

Citation

If you use this code, please cite the associated C3PO Cell Systems publication.

Status

This repository contains the analysis code associated with the C3PO study. It is provided primarily as a record of the code used to perform the published analyses and is not intended to function as a general-purpose software package.
